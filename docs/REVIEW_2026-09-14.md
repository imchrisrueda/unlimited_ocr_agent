# Revisión de mejoras del 14 de septiembre de 2026

Alcance: entrada de imágenes, usabilidad CLI, progreso, OCR secuencial,
filtrado de diagramas y gestión de memoria. Se conserva el contrato de
`AGENTS.md`: ausencia de invención, fuente visual por documento, normalización
autorizada y entregables canónicos de estadillo.

## Correcciones

- La CLI libera recursos con `ExitStack`, también si falla OCR, VLM o exportación.
  La limpieza ocurre al retornar de `main`, sin esperar a finalizar Python.
- Las conversiones CLI usan una carpeta temporal exclusiva y conservan el nombre
  original del documento, evitando colisiones y nombres aleatorios de entrega.
- La conversión de imágenes cierra documentos y objetos Pillow incluso al fallar.
  La API de preparación sin directorio explícito crea un directorio exclusivo;
  el consumidor es responsable de eliminarlo cuando ya no necesite el PDF.
- El OCR secuencial conserva los saltos de línea originales al leer y concatenar
  páginas; únicamente añade el delimitador estructural `<PAGE>`.
- Un HTTP 404 al descargar un modelo no demuestra que esté descargado: ahora
  activa el fallback CLI. El inventario CLI se lee en JSON, evitando interpretar
  líneas decorativas como modelos.
- Los ejemplos de ayuda preservan literalmente las rutas Windows y `--verbose`
  ofrece diagnóstico de entrada, perfil y modelos.

Referencias del mecanismo de memoria:
[API de descarga](https://lmstudio.ai/docs/developer/rest/unload) y
[inventario CLI JSON](https://lmstudio.ai/docs/cli/local-models/ps).

## Verificación

Suite `unittest discover -s tests` y validación `scripts/projectctl.py validate`.
Resultado final: 451 pruebas, 8 omitidas, sin fallos; validación del proyecto
sin diagnósticos y `git diff --check` sin errores. Las pruebas se ejecutaron
fuera del sandbox, necesario para las operaciones temporales de Windows.
Las pruebas de memoria usan simulaciones; no certifican una cantidad de VRAM
liberada ni la calidad OCR de un documento real. Las mediciones de tiempos y
VRAM del walkthrough externo corresponden a su ejecución previa y no se
presentan como resultados reproducidos en esta revisión.

Los archivos `.agents/agents/*/agent.md` describen roles especializados.
Su presencia no cambia la orquestación Python ni activa agentes automáticamente.
La configuración `.vscode/settings.json` recoge preferencias del editor.
